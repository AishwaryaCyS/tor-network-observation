# Tor Network Observation

A beginner-friendly cybersecurity project exploring Tor onion routing and network traffic analysis using Wireshark.

## Objectives

- Understand how Tor routes traffic through multiple relays.
- Learn the role of entry, middle, and exit relays.
- Observe network traffic generated by Tor Browser.
- Compare basic network observations with ordinary browser traffic.

## Tools Used

- **Tor Browser:** For privacy-focused web browsing through the Tor network.
- **Wireshark:** For capturing and inspecting network packets.
- **Windows:** Initial experiment environment.
- **GitHub:** Project documentation and version control.

## Concepts Explored

### Onion Routing

Tor routes traffic through a circuit of relays. Each relay handles a layer of the routing information, helping separate the user's original IP address from the destination website.

### IP Addressing

An IP address identifies a network interface or endpoint for communication. With Tor, the destination website normally sees the Tor exit relay's IP address rather than the user's public IP address.

### Packet Analysis

Wireshark can help observe connections, protocols, packet timing, and traffic between the computer and Tor relays. Because Tor encrypts traffic inside its network, a local packet capture does not ordinarily reveal the contents of visited web pages.

## Safety and Privacy

- Use only legitimate Tor Browser downloads.
- Do not attempt to access systems without authorization.
- Avoid downloading unknown files from untrusted websites.
- Do not publish packet captures containing personal or sensitive network information.
- Remember that Tor improves privacy but does not guarantee complete anonymity.
